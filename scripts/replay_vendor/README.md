# Replay Markdown dependencies

The replay controller uses the blockquote source ranges from CommonMark to remove private host transcripts from finding evidence. The two unmodified pure-Python wheels run locally from the checkout. Their distributions include their MIT licenses. The isolated reader checks each archive against the SHA-256 published by PyPI before import.
